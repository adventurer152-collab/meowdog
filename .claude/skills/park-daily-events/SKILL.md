# 每日最近公園活動

目的：讓使用者一眼知道「今天走路就到得了的公園裡有什麼可以參加」。資訊錯了會讓人白跑一趟，所以寧可寫「未找到」也不要猜。

## 1. 時間與位置

- 用台灣時間（Asia/Taipei）取得今天日期與星期，例如 `TZ=Asia/Taipei date '+%Y-%m-%d %A %H:%M'`。週末、國定假日活動較多，平日多半只有固定課程。
- 位置：用使用者給的地址／捷運站／地標；沒給就用 **台北捷運松江南京站**。
- 半徑預設 **1.5 公里**（步行約 20 分鐘）。符合的公園少於 3 座時擴大到 **3 公里**，並在開頭註明「已擴大範圍」。

## 2. 找最近的公園

- 有地圖／地點搜尋工具（如 places_search）就用它查「公園」「綠地」「河濱公園」，依距離排序。沒有的話用 WebSearch，以「[位置] 附近 公園」「[行政區] 公園 列表」查，並用地址估算直線距離（標「約」）。
- 取最近的 **3–5 座**，太小的街角綠地可略過，除非它常辦活動。
- 每座公園記下：名稱、距離、地址或入口、寵物規定。台北市公園一般可帶牽繩犬隻，但部分區域（兒童遊戲場、草坪特定區）禁入；若有寵物活動區／狗狗公園要特別標出來，因為使用者常帶毛孩出門。

## 3. 查今天的活動

每座公園分別搜尋，優先官方來源：

1. 主管機關：臺北市政府工務局公園路燈工程管理處（parks.taipei）、新北市景觀處等的活動公告與場地借用公告。
2. 市府活動總表：臺北旅遊網活動、臺北市政府新聞稿、各區公所與里辦公處公告。
3. 主辦單位：市集、表演團體、品牌活動的官網／FB／IG／Accupass 頁面。
4. 搜尋字串範例：「[公園名] 活動 [今天日期，如 10/17]」「[公園名] 市集 [本月]」「[公園名] [本月] 活動」「[行政區] 週末 活動 公園」。

判斷「今天有效」：

- 檢查活動期間、日期、星期、場次時間；跨多日的活動確認今天在範圍內。
- 戶外活動注意「雨天取消／延期」公告，有就寫出來。
- 需報名、額滿、限居民、限年齡等條件要列出。
- 過期、找不到年份、或只寫「每週六」卻沒有近期佐證的，**不算今日活動**，放到「日期待確認」。
- 完全查不到就寫「今日未找到公開活動」，不要編造活動名稱、時間或價格。

## 4. 輸出格式

開頭一行：

> 📍 [位置]｜[YYYY/MM/DD（星期X）]｜半徑 [1.5 公里／已擴大至 3 公里]

接著依距離列每座公園：

```
### [公園名]（約 [距離]）
- 寵物規定：[可牽繩入園／有寵物活動區／部分區域禁止…；查不到寫「未查到，依現場公告」]
- 今日活動：
  - [時間] [活動名稱]：[一句話內容]｜[免費／費用]｜[需報名？]
  - （沒有則寫「今日未找到公開活動」）
- 日期待確認：[可省略]
- 來源：[連結]
```

最後一句總結：「今天 [N] 座公園中有 [M] 座查到活動。」再附 `Sources:` 清單（只列實際用到的連結）。

## 5. 每日自動執行

若使用者要每天自動收到：提議建立排程（scheduled task），每天早上（例如 07:45 台灣時間）執行本技能，提示詞寫成完整獨立指令，包含預設位置與半徑。建立前先跟使用者確認時間與位置。
